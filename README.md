DRIVEX
DRIVEX is a 3D driving game that can be played using a web browser.Ithas beed built using JavaScript and Three.js.

Development Status

Stage 1 - Building Foundation of the Game

The foundation stage of the game includes the setting up of the Three.js enviornment along with setup of renderer, camera, lighting and game container.

Features Planned

1.3D driving game enviornment
2.Sports car that can be controlled by the player
3.Third-person camera view
4.Cockpit/first-person camera view
5.Artificial intelligence based traffic
6.Driving physics
7.Collision detection mechanism
8.Speedometer and HUD
9.Environement details
10.Audio 
11.Visual effects
12.Deployment in browser

Technology Used

1.HTML5
2.CSS3
3.JavaScript
4.Three.js

Development Methodology

DRIVEX is being built using an incremental methodology.
